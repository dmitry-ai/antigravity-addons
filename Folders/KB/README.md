# Project Folders: Иерархический менеджер проектов для Google Antigravity 2.0

Официальное расширение пользовательского интерфейса (**UI Extension / Sidecar Plugin**) для группировки проектов Antigravity по папкам и категориям в правой панели (**Auxiliary Pane**).

---

## 1. Как это устроено и почему это 100% безопасно

1. **Изолированный процесс**: Расширение работает как официальный сабпроцесс (**Sidecar**) под управлением встроенного в Antigravity супервизора процессов. Сбой в коде сайдкара физически не способен уронить главное окно программы или повлиять на работу агентов.
2. **Нулевое вмешательство в бинарники**: Ни `app.asar`, ни `language_server.exe` не модифицируются. Плагин устанавливается штатно в `%USERPROFILE%\.gemini\config\plugins\project-folders` и переживает любые автоматические обновления Antigravity без необходимости перепатчивания.
3. **Безопасность данных**: Плагин работает в режиме **Read-Only** по отношению к внутренним базам Antigravity (`conversation_summaries.db` и `agyhub_summaries_proto.pb`). Ваша пользовательская структура папок хранится в изолированном каталоге расширения:  
   `%USERPROFILE%\.gemini\antigravity\sidecar_data\project-folders\folders\data\folders.json`
4. **Нативная интеграция**: Переключение на выбранный диалог любого проекта осуществляется через официальный хостовый мост `window.sidecar.ui.toggleConversation()`.

## 3. Быстрый старт и развертывание

### Установка плагина
Плагин уже развернут в каталог профиля Antigravity:
`%USERPROFILE%\.gemini\config\plugins\project-folders`

Если вы редактируете исходники в `code/` и хотите синхронизировать их с рабочей конфигурацией:
```powershell
Set-Location 'C:\work\research\provision\code\Software\Google\AI\Antigravity\primary\tools\Folders\code'
node deploy.js
```

### Включение в интерфейсе Antigravity
1. Откройте Antigravity.
2. В левом нижнем углу сайдбара нажмите кнопку **Customizations** -> вкладка **Installed**.
3. Убедитесь, что переключатель напротив **Project Folders** находится во включенном состоянии (он включается автоматически при установке).
4. Откройте любой диалог.
5. В правом верхнем углу окна диалога нажмите меню **⋮** (три точки) -> пункт **Extensions** -> выберите **Project Folders**.
6. В правой части окна откроется интерактивная панель с вашим деревом папок.

## 4. Возможности панели «Папки проектов»

- **Иерархия папок**:
  - Создание папок любого назначения («Клиенты», «Внутренние проекты», «Архив», «Личное» и т.д.).
  - Выбор цветовых меток для визуальной идентификации категорий.
  - Сворачивание и разворачивание папок (состояние сохраняется).
- **Распределение проектов**:
  - Каждый проект отображает количество связанных диалогов и дату последней активности.
  - Назначение проекта в любую папку в один клик через выпадающий список `📁 Папка`.
  - Проекты, еще не добавленные в папки, аккуратно собраны в секции *«Без папки»*.
- **Быстрый поиск**:
  - Мгновенная фильтрация по названию папки, проекта или заголовку любого диалога прямо при вводе в строку поиска.
- **Навигация**:
  - Клик по любому диалогу внутри проекта моментально открывает его в основном окне чата.
- **Синхронизация**:
  - Кнопка 🔄 в шапке панели позволяет принудительно перечитать свежие проекты и чаты из Antigravity.
