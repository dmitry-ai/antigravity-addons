# Иерархические папки проектов в левом списке Antigravity (Способ 1 из ответа 16)

Инструмент добавляет многоуровневые иерархические папки непосредственно в список `Projects` Antigravity 2.0. Все существующие проекты и разговоры сохраняют свои штатные ID, ссылки и действия.

## Модель данных (Parent References)

Хранение организовано через единый плоский список папок с полем `parentId`:
- `parentId: null` — папка находится в корне `Projects`.
- `parentId: "<folder-id>"` — папка является дочерней (подпапкой).
- Конфигурация: `C:/work/research/provision/code/Software/Google/AI/Antigravity/primary/tools/Folders/code/folders.json`.

Одинаковые названия папок разрешены в разных ветках дерева (например, `Upwork / 2026` и `Личное / 2026`), а уникальность контролируется строго среди непосредственных потомков одного родителя.

## Управление через графический интерфейс (UI)

- **Создание папки с учётом контекста:** 
  - Нажатие кнопки `📁+` в заголовке `Projects` автоматически определяет текущую активную папку (по наведению курсора, фокусу, активному проекту или выбранному разговору в списке) и выбирает её в качестве родителя по умолчанию.
  - В модальном диалоге создания добавлен выпадающий селектор «Расположение (родитель)» с наглядным отображением дерева и отступами (`↳ `). Пользователь может в один клик переключиться в «📁 Корень (без родителя)» или выбрать любую другую папку.
  - На строке каждой папки при наведении отображается прямая кнопка `📁+` («Создать подпапку в этой папке»), сразу открывающая диалог с предвыбранным родителем.
- **Создать корневую папку напрямую:** меню `⋯` на любой папке → «➕ Создать новую корневую папку», либо через выбор «📁 Корень (без родителя)» в модальном селекторе.
- **Создать подпапку:** кнопка `📁+` на папке, либо меню `⋯` (или правый клик) на папке → «📁➕ Создать подпапку…».
- **Переместить папку:** меню `⋯` / правый клик на папке → «↗️ Переместить папку…». В выпадающем списке отображаются доступные пути предков (например, `📁 (В корень)`, `📁 Upwork / 2026`). Защита от циклов автоматически исключает саму папку и всех её потомков.
- **Переименовать папку:** меню `⋯` / правый клик → «Переименовать папку», либо клавиша `F2`, когда курсор наведён на папку. `Enter` сохраняет новое имя, `Esc` отменяет ввод.
- **Удалить папку:** меню `⋯` → «Удалить папку». При удалении родительской папки её непосредственные подпапки и проекты автоматически поднимаются к её родителю (или в корень), сохраняя целостность структуры. Сами проекты Antigravity не удаляются.
- **Добавить/переместить проект в папку:** правый клик на карточке проекта → выбор целевой папки с отображением полных путей (`📁 Upwork / 2026`). Либо «В новую папку…».
- **Убрать проект из папки:** правый клик на карточке проекта → «📤 Убрать из папки (вернуть в корень)».
- **Перетаскивание мышью (Drag & Drop):**
  - Папку можно перетащить мышью на заголовок любой другой папки для изменения родителя и создания подпапки (с автоматической проверкой циклов и блокировкой коллизий имён).
  - Перетаскивание папки на заголовок `Projects` перемещает её в корень (снимает родителя).
  - Проект можно перетащить мышью на заголовок любой папки для добавления в неё.
  - Перетаскивание проекта на заголовок `Projects` убирает его из папки в корень.
  - При перетаскивании целевая папка подсвечивается контрастной синей рамкой (`.folder-drop-target`).
  - `Alt + Drag` сохраняет исходный Antigravity-механизм изменения порядка строк.

## Отображение в виртуальном списке и систематическая иерархия отступов

- **Систематические отступы по глубине:** заголовки папок, карточки проектов (`button[data-project-card]`), строки разговоров и заглушки пустых папок получают динамические отступы на базе древовидной глубины (`--folder-depth`, `--folder-indent-unit: 14px` и атрибута `data-folder-depth="0..12"`). Инлайн-инъекция переменной `--folder-depth` снимает ограничения на максимальную глубину.
- **Сквозная иерархия проектов:** проект, находящийся в подпапке глубины $D$, получает отступ $D + 1$, что визуально выстраивает его строго под родительской папкой, а не сбрасывает на базовый уровень.
- **Выравнивание иконок:** эмодзи папок `📁` (базовый отступ 8px) и векторные иконки проектов `📂` (базовый отступ 4px + 4px внутри 24px контейнера) на одном и том же уровне выровнены по единой вертикальной оси ($X = 8\text{px} + D \times 14\text{px}$), а их текстовые метки и строки разговоров начинаются с единой горизонтальной координаты ($X = 30\text{px} + D \times 14\text{px}$).
- **Стрелки раскрытия папок (chevrons):** аккуратно видны как в свёрнутом (`>`), так и в развёрнутом (`v`) состоянии с плавным осветлением при наведении, обеспечивая мгновенную читаемость структуры папок.
- **Сворачивание папки:** при сворачивании родительской папки скрываются все её подпапки и проекты. Проекты закрытой ветки **не вываливаются в корень списка**.
- **Статус пустоты:** папка не считается пустой и не отображает `(папка пуста)`, если содержит подпапки (даже если у неё нет прямых проектов). Для пустых папок заглушка `(папка пуста)` отображается с отступом $D + 1$.

## Управление через CLI (`folders-manager.js`)

```bash
# Показать дерево папок и распределение проектов
node folders-manager.js list

# Список всех зарегистрированных проектов Antigravity
node folders-manager.js projects

# Создать корневую папку или подпапку
node folders-manager.js add-folder "2026" "folder-upwork"

# Переместить папку в другого родителя (или в корень: root)
node folders-manager.js move-folder "2026" "Upwork"
node folders-manager.js move-folder "2026" root

# Переименовать папку
node folders-manager.js rename-folder "2026" "Архив 2026"

# Удалить папку (подпапки и проекты поднимаются к родителю)
node folders-manager.js remove-folder "folder-2026"

# Назначить проект в папку
node folders-manager.js assign "howaboutnope.com" "2026"

# Вернуть проект в корень
node folders-manager.js unassign "howaboutnope.com"
```
