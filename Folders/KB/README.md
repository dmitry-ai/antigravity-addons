# Project Folders: Иерархический менеджер проектов для Google Antigravity 2.0

Инструмент организации проектов и диалогов в Google Antigravity 2.0 непосредственно в основном левом списке **Projects** (**Способ 1 из ответа 7**, расширенный полным интерактивным UI — **Способы 1 и 2 из ответа 13**).

---

## 1. Как это устроено

1. **Интеграция в левый сайдбар**:
   Проекты группируются в интерактивные сворачиваемые папки непосредственно в основном списке `Projects` левой панели Antigravity.
2. **Полноценное управление через UI (мышью и клавиатурой)**:
   - Кнопка создания папки `📁+` в основном заголовке `Projects`.
   - Контекстное меню папки `⋯` и правый клик: переименование, удаление, создание новой папки.
   - Контекстное меню проекта (правый клик): перемещение проекта в любую папку или извлечение в корень.
   - Быстрое переименование папки по клавише `F2` (инлайн-редактирование на месте).
   - Перетаскивание проектов мышью (**Drag & Drop**) прямо на строки папок с подсветкой цели.
3. **Мгновенные обновления без перезагрузки (Zero Reload)**:
   Все операции в UI не требуют нажатия `Ctrl+R` — список проектов перерисовывается моментально благодаря интеграции с внутренним реактивным хранилищем Antigravity.
4. **Отображение пустых папок**:
   Только что созданные или пустые папки всегда видны в дереве (`📁 Название (0)` / `(папка пуста)` при раскрытии).
5. **Сохранение состояния**:
   Свернутые и развернутые папки сохраняются в штатном персистентном стейте Antigravity (`sidebar_collapsed_section_headers`) и переживают перезапуски.

## 3. Инструкция: Как управлять папками и проектами

### Способ 1: Прямо через интерфейс Antigravity (UI, мышь и клавиатура)

#### 1. Создание папки
- Нажмите на кнопку **`📁+`** в правом верхнем углу заголовка **Projects** (рядом с кнопкой создания проектов).
- В появившемся окне введите название папки и нажмите **Enter** (или кнопку «Создать»).
- Папка мгновенно появится в списке сайдбара.

#### 2. Переименование папки
- **Мышью**: наведите курсор на строку папки, нажмите кнопку **`⋯`** справа (или кликните правой кнопкой мыши по папке) и выберите **«Переименовать папку»**.
- **Клавиатурой**: наведите курсор / фокус на папку и нажмите клавишу **`F2`**.
- Название превратится в поле ввода прямо в строке папки. Отредактируйте имя и нажмите **Enter** для сохранения (или **Esc** для отмены).

#### 3. Удаление папки
- Нажмите **`⋯`** на строке папки (или кликните правой кнопкой мыши) и выберите **«Удалить папку»**.
- > [!IMPORTANT]
  > При удалении папки сами проекты **не удаляются**! Они автоматически возвращаются на верхний уровень списка (в корень).

#### 4. Добавление проекта в папку
- **Перетаскиванием (Drag & Drop)**: захватите строку проекта мышью и перетащите её на нужную папку. При наведении папка подсветится синей пунктирной рамкой. Отпустите кнопку мыши — проект перемещен!
- **Через меню проекта**: кликните правой кнопкой мыши по проекту, в меню выберите **«В папку "..."»**. Проект сразу переместится в выбранную папку.

#### 5. Удаление проекта из папки (возврат в корень)
- **Перетаскиванием**: перетащите проект на заголовок **Projects** в самом верху или в область проектов без папки.
- **Через меню**: кликните правой кнопкой мыши по проекту в папке и выберите **«Убрать из папки (вернуть в корень)»**.

### Способ 2: Консольная утилита `folders-manager.js`

Если вам удобнее работать через терминал:
```powershell
Set-Location 'C:\work\research\provision\code\Software\Google\AI\Antigravity\primary\tools\Folders\code'

# Дерево папок и проектов
node folders-manager.js list

# Список всех проектов Antigravity
node folders-manager.js projects

# Создать папку
node folders-manager.js add-folder "Маркетинг"

# Переименовать папку
node folders-manager.js rename-folder "Маркетинг" "Маркетинг и PR"

# Удалить папку (проекты возвращаются в корень)
node folders-manager.js remove-folder "Маркетинг и PR"

# Добавить проект в папку (по имени или подстроке)
node folders-manager.js assign "howaboutnope" "Upwork"

# Удалить проект из папки (вернуть в корень)
node folders-manager.js unassign "howaboutnope"
```

## 4. Безопасность и надежность

- **`app.asar` не тронут**: Решение использует внешний мост `bootstrap.js` из задачи UI.
- **Graceful Fallback**: При несовпадении анкоров в коде бандла отдается исходный оригинальный код.
- **Базы данных в безопасности**: Внутренние базы Antigravity (`conversation_summaries.db`) не затрагиваются.
- **Сетевые порты не создаются**: Обработка REST API происходит внутри Electron через `protocol.handle()`.
- **Откат в один клик**: `node uninstall-folders.js` мгновенно отключает хук.
