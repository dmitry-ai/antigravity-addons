# Папки проектов в левом списке Antigravity

Инструмент добавляет группы папок непосредственно в `Projects`. Существующие проекты и разговоры сохраняют свои штатные ID и действия.

## Управление мышью и клавиатурой

- **Создать папку:** кнопка `📁+` рядом с `Projects`; введите название и нажмите `Enter` или «Создать». К кнопке можно перейти клавишей `Tab` и открыть её через `Enter`.
- **Переименовать:** меню `⋯`/правый клик на папке → «Переименовать папку», либо `F2`, когда фокус находится на папке. `Enter` сохраняет, `Esc` отменяет.
- **Удалить папку:** её меню → «Удалить папку». Проекты возвращаются в корень `Projects`; сами проекты не удаляются.
- **Переместить проект:** правый клик на проекте → выбрать папку назначения.
- **Убрать из папки:** меню проекта → «Убрать из папки (вернуть в корень)».
- **Перетаскивание:** обычное перетаскивание проекта использует папки как цели; заголовок `Projects` служит целью возврата в корень. `Alt` оставляет исходный обработчик изменения порядка Antigravity. Эта часть пока не подтверждена отдельным тестом с реальной мышью.

Пустые папки видны. Сохранённые через UI изменения обновляют список через событие конфигурации и React, без перезагрузки страницы.

Конфигурация: `C:/work/research/provision/code/Software/Google/AI/Antigravity/primary/tools/Folders/code/folders.json`.

CLI доступен как дополнительный инструмент: `node folders-manager.js list`, `add-folder`, `rename-folder`, `remove-folder`, `assign`, `unassign`.

## Подключение и диагностика

Модуль подключён через `primary/tools/CSS/code/bootstrap.js`. Перезапуск основного процесса нужен для изменений самого `folders-bootstrap.js`. Изменения клиентского контроллера и патчера подхватываются при следующей загрузке рендерера. Сохраните незавершённый ввод перед ручным `Ctrl+R`.

Ошибки загрузки находятся в `%APPDATA%/Antigravity/logs/main.log` под метками `[folders-bootstrap]` и `[folders-patch]`. Несовместимые анкоры или ошибка синтаксиса преобразованного бандла приводят к возврату исходного интерфейса с записью в журнале.

## Проверка исправления 2026-10-12

Причина исчезновения папок после изменения №14: отсутствовал `const path = require('path')` в `folders-bootstrap.js`, хотя использовался `path.join`. В журнале зафиксирован `ReferenceError: path is not defined`. Прежний набор «21/21» не загружал этот модуль и не проверял UI.

Текущий `test-suite.js` запускает поведенческие проверки `test-regressions.js`: загрузку Electron-модуля с реальным обработчиком, все пять операций в изолированной конфигурации и настоящий генератор строк из клиентского бандла. Дополнительно проверяются сохранение ID, скрытие потомков при сворачивании папки, пустые папки и отсутствие группировки в истории.

В открытом Antigravity подтверждены видимые папки, кнопки управления, создание временной папки через кнопку и Enter, переименование через F2 и Enter и обновление названия без Ctrl+R. Временная папка удалена через менеджер; SHA-256 исходной конфигурации полностью совпал с резервной копией. Перетаскивание и удаление через подтверждающий UI-диалог не заявляются как проверенные вручную.
