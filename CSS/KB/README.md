# Компактное оформление Antigravity

CSS подключается внешним загрузчиком Tools через CDP inspector stylesheet. `app.asar`, штатные CSS и клиентский JavaScript Antigravity не изменяются. Установка и диагностика: [Upgrade](C:/work/research/provision/code/Software/Google/AI/Antigravity/primary/tools/Upgrade/KB/README.md).

## Исходники

`CSS/code/style.less` задаёт размеры и импортирует `less/compact.less`, `less/folders.less`, `less/indent.less`, `less/chat.less`. `style.css` — результат сборки.

```powershell
node 'C:/work/research/provision/code/Software/Google/AI/Antigravity/primary/tools/CSS/code/build.js'
```

Фоновый Tools наблюдает за Less и пересобирает его после сохранения. Новая таблица применяется во всех подключённых окнах без перезагрузки. При ошибке сборки остаётся последняя корректная версия, ошибка отражается в состоянии Tools и проверке Upg.

Основные размеры: строки дерева 16 px, межстрочный размер текста 14 px, вложенность 14 px. `--antigravity-tree-row-height` — общий источник высоты для собственного виртуального списка Folders и CSS. Нельзя менять высоту видимой строки отдельно от расчёта виртуальных позиций.

По настройке пользователя в обоих профилях скрыты системный проект `Outside of Project` и раздел бесед без проекта `Conversations`. В `style.less` это задают `--antigravity-hide-outside-project: 1` и `--antigravity-hide-standalone-conversations: 1`. Значение `0` возвращает соответствующий раздел. Folders читает эти параметры до расчёта виртуальных строк, поэтому пустых мест и неверных позиций прокрутки не остаётся. Исходные проекты, беседы и их привязки не изменяются; фильтр использует точный системный ID, а не имя обычного проекта.

Штатные меню могут находиться вне sidebar, поэтому компактные правила адресованы `[role=menu]` и `data-testid` выбора модели. Строка штатного меню — от 20 px, собственных меню Folders и выбора расположения — 16 px. Триггеры модели и разрешений — 22 px. В переписке боковые поля — 4 px, нижнее поле — 2 px, высота строки текста — 18 px. Правила общего вида `div {height:...}` или `button {padding:...}` для всего приложения не используются.

Внутренний пустой блок в конце переписки и нижний градиент уменьшены с 48 до 4 px. С последней реплики снята минимальная высота, которая растягивала короткий ответ до высоты окна. Вложенные панели действий больше не добавляют 12 px слева; текст их строк начинается в 8 px от границы переписки. Пустые контейнеры карточек не занимают место, отступ перед кнопками под ответом — 2 px. Эти правила находятся только внутри `conversation-view` и проверяются на открытом разговоре через CDP, включая состояния работы агента и законченного ответа.

`folders-view.css` содержит геометрию самостоятельного дерева и добавляется после общей таблицы. Старые правила native sidebar остаются для переключения к штатному списку. Удалённые AST-преобразования и имена минифицированных React-компонентов для CSS больше не нужны.

При изменении структуры native UI меняется только адресованное этому UI правило. Собственное дерево сохраняет свою разметку. Проверять нужно вычисленные размеры через CDP и снимок `Page.captureScreenshot`; снимок скрытого/свёрнутого окна в этой сборке не возвращается, для него окно должно быть видно.

Рабочий манифест использует `cdp-runtime.js`. Прежние загрузчик CSS и команды изменения ASAR удалены.
