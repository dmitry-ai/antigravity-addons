# 1. Общий механизм восстановления

Добавлены `Upgrade/code/upgrade.js`, `archive.js`, `host.js`, `registry.js` и `bootstrap.js`. Реестр автоматически обнаруживает `code/tool.json`, проверяет зависимости и подключает каждый включённый модуль один раз на окно. Старый CSS-хук при установке мигрирует в общий загрузчик.

# 2. Архив и резервные копии

Изменяемый файл добавляется в область данных ASAR; в копии исходного заголовка обновляются его смещение, размер и SHA-256. Остальные данные и метаданные сохраняются. Пробная сборка, контроль файлов, проверка процессов, блокировка параллельных запусков и проверки хешей предшествуют замене. Откат разрешён только для совпадающего установленного архива и версии.

# 3. CSS

Из `CSS/code/bootstrap.js` убрано ручное подключение Folders. Добавлены сборка Less и наблюдение за исходниками. `patch.js` и `restore.js` перенаправлены к общему механизму, чтобы прежние команды использовали те же проверки и резервные копии.

# 4. Folders

Добавлен `folders-layout.js`. В `folders-patch.js` вместо сравнения точных минифицированных фрагментов используются найденные в AST участки и имена переменных. Сохранены существующая логика дерева, оригинальное тело рендеринга проектов и совместимые экспортируемые константы.

`folders-bootstrap.js` проверяет дерево перед использованием конфигурации, закрывает файловые наблюдатели при закрытии окон и учитывает изменения адаптера в ключе кеша. Неизвестная структура клиента оставляет штатный интерфейс и фиксирует ошибку в журнале. Установка и отключение Folders теперь меняют его манифест, не редактируя чужой bootstrap.

# 5. Форматирование прежнего JavaScript

Удалены пустые строки. Строковые литералы по возможности приведены к одинарным кавычкам. Константы в сопоставлениях расположены слева. Сохранены существующие отступы и комментарии; новые строки используют табуляцию.

В функциях с несколькими выходами результат собирается в `r` и возвращается одним `return`. Для сохранения прежних ранних выходов без изменения существующих отступов используются локальные блоки с меткой `result`. Короткие блоки `if/else` расположены раньше длинных. Исходники предыдущих задач в `ꙮ` не переформатировались.

# 6. Less

`style.less` импортирует три тематических файла. Вложенность убирает повторение длинного селектора сайдбара, переменная задаёт шаг отступа, циклы заменяют перечисление уровней дерева. Сохранены 29 блоков исходных комментариев; при актуализации документации их описания диапазонов и геометрии уточнены. Сравнение селекторов и деклараций подтверждает эквивалентность 117 блоков правил до и после преобразования.

# 7. Запуск и руководство

Добавлены PowerShell-лаунчер, скрипт создания ярлыка, фиксированные зависимости и тесты. Ярлык `Antigravity - Upgrade.lnk` создан на Рабочем столе Windows. Руководство описывает восстановление после обновления, откат, расширение реестра, правку Less и диагностику несовместимых будущих версий.

# 8. Актуальная документация модулей

Руководства CSS и Folders обновлены под текущий код вместо примечания над прежней инструкцией. Указаны исходники Less, общий загрузчик, зависимости, область действия старых обёрток, расположение и сохранение резервных копий, различие автоматической сборки, перезагрузки интерфейса и полного перезапуска. Архитектурное руководство Folders описывает поиск в AST, фактические отступы и используемые поля конфигурации. Справка CLI и существующие комментарии приведены в соответствие с поведением скриптов; логика операций не изменялась.

# 9. Фоновый Node-процесс после обновления — 16 октября 2026

В Antigravity 2.24.0 после закрытия окон обнаружен sidecar, запущенный через `agy-node.cmd` с `ELECTRON_RUN_AS_NODE=1`. Прежняя проверка `tasklist` учитывала только имя `Antigravity.exe` и ошибочно запрещала восстановление.

Проверка получает процессы через Windows CIM. Из блокировки исключается только запуск с совпадающими аргументами дочернего процесса и родителя `cmd.exe`, если штатный `Antigravity/bin/agy-node.cmd` содержит установку Node-режима и вызов того же EXE. Недоступные сведения, изменённая обёртка и любые неподтверждённые процессы сохраняют блокировку. Проверка повторяется перед заменой архива; ошибка теперь содержит PID мешающих процессов.

Добавлены регрессионные проверки фонового sidecar, настоящего приложения, недоступных сведений, отсутствующей или изменённой обёртки. Все 12 тестов пройдены. Подключение CSS и Folders восстановлено в установленной версии 2.24.0 без завершения sidecar, проверены 347 внешних файлов; последующий `--check` успешен. Руководство и скрипт создания ярлыка используют фактическое имя `Upg`.
